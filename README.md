# 📊 Cottonil Sales & Inventory Data Analytics Project

An end-to-end Data Analytics & BI project for **Cottonil**, covering raw dataset transformation, automated Python data cleaning pipelines, and interactive executive dashboards in Power BI.

---

## 📁 Repository Structure

```text
├── cleaned data/            # Processed and cleaned Excel datasets
├── uncleaned data/          # Raw datasets prior to transformation

├── SALES.PY                 # Sales data cleaning & date distribution script
├── DICOUNT.PY               # Discounts & promos analysis script
├── Purchase_cleaning.py     # Procurement & purchase data cleaning script
